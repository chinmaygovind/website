The model

Treat the stick of chalk as a spring. Your hand moves along the board at speed V; the tip is displaced x from where the hand would put it (negative means it lags behind), so the tip slides over the board at u = V + ẋ. Friction drags it backwards, and how hard the tip presses on the board depends on how the chalk is bent: lean it so it is pushed and friction digs the tip in harder (κ > 0); pull it and friction lifts it (κ < 0).

ẍ + 2ζẋ + x = −μ(V + ẋ) · N, N = max(0, P − κx) μ(u) = (μd + (μs − μd) e−|u|/vs) · tanh(u/ε) μs = 0.8, μd = 0.4, vs = 0.5, ε = 0.02

Static friction beats sliding friction, so μ falls as the slip speed rises. The tanh is a smoothed sign: it lets the tip stick (u = 0, the dashed "stuck" line in the state space) without a separate stuck mode. When N hits zero the chalk is off the board: no friction and no chalk, which is where the gaps between the dots come from.

The steady glide is the fixed point ẋ = 0, x* = −μ(V)P / (1 − μ(V)κ). Linearise about it:

ξ̈ + (2ζ + μ′(V) N*) ξ̇ + (1 − μ(V)κ) ξ = 0, N* = P / (1 − μ(V)κ)

μ′(V) < 0, so friction subtracts damping, more the harder you press. The trace crosses zero with the determinant positive, so a complex pair of eigenvalues crosses the imaginary axis: a Hopf bifurcation, at

Pc = 2ζ(1 − μ(V)κ) / |μ′(V)|

Press harder: past Pc. Push instead of pull (κ up): Pc drops. Draw slowly: |μ′| is largest near zero speed, so Pc drops again, which is why a slow careful line squeaks and a quick flick does not. A stiffer, better-damped stick (ζ up) raises it, which is why snapping the chalk in half helps.

The Hopf is subcritical: a kick starts a stick-slip cycle well below Pc, and once it is going you have to ease off a long way to stop it. The bifurcation diagram runs two simulations per press, one from a glide and one from a kick; where they disagree, both states are stable at once.
