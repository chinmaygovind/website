Three eras. Autocomplete: it guesses the next few lines. Chat: you paste code back and forth. Agent: it lives in your repo, runs things, and you review. The mental model that matters: you are the lead, it is the intern.

my workflow

📖 a CLAUDE.md everywhere

Every folder explains itself: what this is, how to run it, what not to touch. Docs written for the agent.

🧺 tests are the leash

3,000+ tests on my site, and a script that runs only what changed. An agent without tests is a slot machine.

⚡ skills for anything I repeat

/push commits, deploys and checks the live page. One word instead of ten steps.

👀 look at the real thing

Not the green checkmark. Open the page. Drive the game. Read the diff.

If you steal one thing, steal the CLAUDE.md files. Tests let me say yes to changes I didn't write line by line. And always look at the actual output. Which brings us to...
where it goes wrong

✅ passed, did nothing

My deploy went green for months while the server kept running old code. Nobody had told the script to restart it.

🪓 the slow leak

Test runs left temp files behind until they filled 13GB of RAM. Nothing failed. Everything got slow.

13GB

🤖 confidently wrong

It told me a launch would melt my server. One database query said it wouldn't. Check before you believe.

🧠 what's still your job

Taste. System design. Knowing what to build. Knowing when it's lying.

None of these threw an error. That's the pattern: the dangerous failures are quiet. The fix is always the same: look at the real thing.
